# Backend Marathon Course

Welcome to the Backend Marathon! This repository contains the code and assignments for the entire course, structured day-by-day.

## Course Structure

* **[Day 1](./day1):** AsyncIO & Pydantic
* **[Day 2](./day2):** PostgreSQL Setup & Benchmarking
* **[Day 3](./day3):** API Design & Clean FastAPI Architecture
* **[Day 4](./day4):** Message Brokers (RabbitMQ & Kafka)
* **[Day 5](./day5):** CI/CD & Debugging
* **[Day 6-7](./day6-7):** Final Project - Async Report Engine

## How to use this repository
Inside each day's folder, you will find a `README.md` that contains:
1. The **Goals** for that module.
2. The **Assignments** and code tasks.
3. The **Solutions**, **Mechanics**, and **Logic** explaining the provided code.

Dive into any of the folders above to get started!
